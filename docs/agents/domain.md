# Domain docs

This is a single-context repo. Before exploring a task, read root `CONTEXT.md` and ADRs in `docs/adr/` relevant to that task. Proceed silently if a document is absent.

Use the glossary's terms in issues, plans, tests, and code discussions. If a needed concept is missing, note the gap for domain modeling. Surface any proposal that contradicts an ADR instead of silently overriding it.

The API is under `api/` and the client is under `client/`; both share the root glossary and ADRs.
